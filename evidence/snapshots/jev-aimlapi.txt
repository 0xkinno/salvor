## Model Overview

Jev is TypeSafe's "System One" model: a structured decision model that returns typed answers (yes/no, choice, score, box) with calibrated probabilities instead of generated text. It is built for routing, classification, triage and other in-app decision points where a fast, predictable verdict matters more than prose — typically answering in well under a second. Context window is 262,144 tokens.

`typesafe/jev` is the **floating id**: it always resolves to the current release, today [Jev 1.14](https://docs.aimlapi.com/api-references/decision-models/typesafe/jev-1.14.md), and moves with each new one. Pin [`typesafe/jev-1.14`](https://docs.aimlapi.com/api-references/decision-models/typesafe/jev-1.14.md) or [`typesafe/jev-1.13`](https://docs.aimlapi.com/api-references/decision-models/typesafe/jev-1.13.md) when you need the behaviour to stay put.

Version 1.14 reads experimental images and adds the `box` question — where something is in an image. See [Jev 1.14](https://docs.aimlapi.com/api-references/decision-models/typesafe/jev-1.14.md#images-and-the-box-question) for how to send them.

```python
import requests

response = requests.post(
    "https://api.aimlapi.com/v1/decisions",
    headers={
        "Authorization": "Bearer <YOUR_AIMLAPI_KEY>",
        "Content-Type": "application/json",
    },
    json={
        "model": "typesafe/jev",
        "state": "Help! My payments have been failing for 3 days and nobody answers support.",
        "questions": {
            "is_urgent": {
                "type": "noul",
                "instructions": "Does this convey urgency?",
            },
            "department": {
                "type": "choice",
                "instructions": "Which team should handle this?",
                "criteria": {
                    "billing": "Payments, invoicing, refunds",
                    "technical": "Bugs, outages, integrations",
                    "sales": "Pricing, upgrades, new accounts",
                },
            },
            "frustration": {
                "type": "score",
                "instructions": "How frustrated is the customer?",
                "criteria": ["Calm", "Frustrated", "Very angry"],
            },
        },
    },
)

print(response.json())
```
